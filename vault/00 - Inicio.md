# Parrot OS + Hyprland - Entorno hacker

Boveda con **todo** el trabajo de personalizacion del escritorio, del 1 al 2 de octubre de 2026.

Sistema: **Parrot Security 7.2** (Debian) · **Hyprland 0.55.2** (Wayland) · Ryzen 5 5600G + RX 7600, dos monitores.
Objetivo: entorno hacker elegante, minimalista y sofisticado para Hack The Box, con la paleta generada desde el fondo de pantalla.
